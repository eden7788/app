② Device InstallationController · Hub · Sensor
Partner
Controller Installation
  • Insert the batteries into the controller.
  • Select the protocol matching the AC manufacturer.
    Samsung: C / LG: A / Carrier: try each protocol one by one to find the one that works.
  • Bring the controller close to the AC and run a Bluetooth-based control test. (standalone test, no hub registration)
    • Bluetooth Control Test Example (tap to play video)
  • Check that the controlled values match the AC's LED display (temperature, fan speed).
  • Attach the controller facing the IR receiver.
    Install parallel to the IR receiver / not over the filter / apply an appropriate amount of silicone / fix firmly to prevent falling.
  • After attaching, run the control test once more to confirm normal operation.
Hub Installation
  • Check the signal strength (dBm) with the controllers and sensors, and choose a spot with a good signal.
  • Fix the hub in place.
    Install in an open spot with good signal (not in enclosed spaces like drawers) / fix firmly so it doesn't move.
Sensor Installation
  • Insert the batteries into the sensor.
  • Attach the sensor near the matched AC per the installation standards.
    Avoid outside air, direct airflow, metal plates, heat-emitting devices, and entrances / install in an open spot / keep it visually aligned / seated: 1.3m from floor / standing: 1.5m.
Optional — Additional SeedN Router Install
  • Skip this item if the customer's own router is used.
  • Install an additional SeedN router.
    Connect to the main router by cable (if wireless, a reason must be shared) / attach sticker / complete setup / verify normal communication.

⑦ Floor Plan & RegistrationRecord layout per floor · register in PartnersApp
Partner
Device Labeling
  • H (Hub) — [number+H] e.g. 1H→2H, keeps counting across floors, write the full 12-digit MAC.
  • A (Router) — [floor+letter] e.g. 2 units on floor 1 → 1A, 1B.
  • C (Controller) — [number+C] e.g. 1C, 2C, keeps counting across floors.
  • S (Sensor) — [number+S] e.g. 1S, 2S, keeps counting across floors.
⚠ Numbering RuleNumbers continue across spaces and floors.
If floor 1 ends at 4C, floor 2 starts at 5C.
Floor Plan Registration Checklist
  • Assign numbers in order of importance.
    Lower numbers for the ACs the customer uses most / higher numbers for rarely used or unattended devices.
  • When registering on PartnersApp web, register with the [plan number] + [space name (controller name)] combination.
  • Mark the AC type on the plan.
    e.g. 1-way, 4-way, 360 type / also mark pillars and obstacles.
  • Use the same orientation reference for all floors.
    Single floor: use the entrance / multi-floor: use the stairs (do not mix per floor).
  • PartnersApp [View Location] → [Plan] → [+] → tap the camera icon to register a plan for each floor. (one per floor, no floor skipped)
⚠ Don't mix orientation referencesDon't use different references per floor (e.g. entrance on floor 1, stairs on floor 2). Use the same reference for all floors.

Customer Usage Guide
  • ① Control method — control the AC directly in the app; run a real test together with the customer.
    • Control Method Example (tap to play video)
  • ② Schedule registration — explain how to register automatic operation schedules.
    • Schedule Registration Example (tap to play video)
  • ③ Account guide — hand over the created account info and explain how to change the initial password.
    • Account Guide Example (tap to play video)
  • ④ Explain the SmartLock feature, confirm whether the customer wants it, and report to SeedN.
    What is SmartLock?
    It locks the sync between the app settings and the HVAC device to keep their states aligned.
    Benefit
    It resolves remote-control errors and real-time control mismatches, keeping the store comfortable at an optimized temperature.
    Conditions & Cautions
    · No separate schedule setup is required.
    · Since sync is enforced, for temperature control we recommend using the smartphone app.
    ⚠ Activation note SmartLock is activated only when the customer requests it via a separate request to SeedN.
  • ⑤ Explain the AI feature, confirm whether the customer wants it, and report to SeedN.
    What is AI Mode?
    It uses temperature/humidity sensor readings and the user's preferred-temperature patterns to automatically control heating/cooling in real time.
    Benefit
    Without complex schedules, it curbs excessive cooling/heating while the AC runs and greatly reduces wasted power.
    Conditions & Cautions
    · SmartLock must be enabled first.
    · AI control signals are sent only to ACs that are turned on and running.
    ▲ Activation note The AI feature is activated only when the customer requests it via a separate request to SeedN. After explaining it, be sure to confirm whether they want it and report to SeedN.
